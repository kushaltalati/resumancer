# Review step

The full seven-reviewer panel is built into this skill: follow `references/panel.md`. Do not depend on any external skill.

Flow: write `resume.md` + `job.md` → seven reviewers in parallel → merge → rebuild → recompile → re-screen → `panel.md`. Two rounds maximum. Apply every fix that needs no new fact; collect `[ADD]` questions for the user; never attach a PDF that still contains a placeholder.

With `--no-panel` the step is skipped and the final message says the resume is unreviewed.
